# 更新日志

## 1.12.0

- 作为 plugins 目录下默认关闭的普通插件提供，通过 WebUI 统一启停；模型配置读取当前实例目录。

## 1.11.0

- 配置：新增插件显示数量、兼容性筛选及本地说明优先三个查询偏好，配置页提供中英日文标签与说明，单次调用参数优先。

## 1.10.0

- 插件搜索与排行榜统一到 maibot_plugin_list，通过 sort_by 排序并自动返回统计；单插件统计使用 maibot_plugin_detail，移除独立统计工具。

## 1.9.0

- 工具说明统一使用 description，并按最新调用场景调整。
- 资源链接补齐官网、插件市场、人设分享站，文档地址更新为 docs.maibot.chat。
- 模型分配移除固定 source 字段；文档正文默认 6400、最多 12800 字符。
- 版本查询只返回稳定版，精简版本与更新日志字段，移除预发布开关。

## 1.8.0

- 资源查询：新增 `maibot_resource_link`，提供麦麦一键包 CNB 下载页和麦麦文档的固定链接。

## 1.7.0

- 模型查询：新增 `maibot_model_tasks`，只读查看全部或指定任务的已保存模型分配，展示模型名称、标识和 provider 名称，不暴露密钥及鉴权配置。

## 1.6.0

- 市场列表、统计及 README 改为 SDK `ctx.market` 查询，与主程序和 WebUI 共用数据源与缓存，删除插件内镜像轮询和重复缓存；最低 SDK 版本为 2.15.0。
- 插件查询：明确列表工具同时支持搜索与浏览，新增 `maibot_plugin_detail` 查询完整元信息、版本兼容性和推荐版本。
- 插件查询：列表和排行榜新增 `compatible_only`，直接使用主程序的兼容性判断。
- 查询结果：默认返回简洁摘要，详情省略各版本重复清单；完整清单按需获取，保留缺失统计、全市场排名和来源缓存信息。
- 清理遗留的远程文本获取函数。

## 1.5.0

- 插件市场：新增 `maibot_plugin_stats`，查询单个插件的下载量、点赞／点踩、评分、评分人数、评论数及 7 日／30 日下载和点赞飙升排名。
- 插件市场：支持下载、点赞、评分及四种飙升榜排序，支持搜索、分类筛选和分页。
- 插件列表：`maibot_plugin_list` 新增 `include_stats` 参数，可附带统计数据。
- 统计使用 WebUI 同源插件中心快照，缓存 5 分钟，支持强制刷新；返回数据时间和服务端排名口径，缺失数据不当作零。
