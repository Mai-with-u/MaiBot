# Changelog

## [2.0.1] - 2026-08-21

### 用户感知功能

- 新增“Hello World 页面” WebUI 示例，可从“扩展与集成”菜单打开。
- 页面支持调用插件自身的 `greet` API，并展示插件页面的清理逻辑示例。

### 开发侧

- 新增 `extensions.webui_pages` Manifest 声明和 `webui/dist/index.js` 页面入口示例。

## [2.0.0] - 2026-06-26

### 用户感知功能

- 提供问候、时间查询、复读和消息打印等基础示例能力。

### 开发侧

- 演示 Manifest v2、配置模型、Tool、Command、Action 和 EventHandler 的基础写法。
