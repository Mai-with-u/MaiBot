# PR 2049 修复说明

本次修复用于解除图片记忆与摘要写回的数据完整性、并发和测试阻塞。依照 `src/A_memorix/MODIFICATION_POLICY.md` 的本地例外，改动限定于已核实的 PR 评论问题；实现层归属仍为 A_Memorix 的 `MaiBot_branch`，需随图片记忆实现一并同步上游。本次没有提交、推送或发布上游改动。

元数据 schema 升级至 v26，新增成功空摘要的检查点表。检查点只记录真实聊天流、外部幂等标识和消息计数，不生成可检索记忆段落，也不作为可分享知识包内容导出。

图片嵌入模型不可用时，搜索明确返回错误；已有同图命中仍可使用，并保留不可用状态及原因。失败的图片嵌入与描述补偿任务提供独立重排入口，不再与接收侧图片入库队列混淆。

聊天流查询继续服从当前聊天、共享组及全局共享配置。WebUI 继续使用现有统一管理认证，未增加评论所假设的普通用户权限模型。

图片嵌入请求要求 HTTPS，仅允许明确的本机回环 HTTP 地址。远程或局域网 HTTP Provider 需要配置 HTTPS 后才能发送图片；认证方式及其他模型请求保持现有行为。
