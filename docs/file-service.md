# 文件服务

文件功能运行在主程序中，不依赖 WebUI 或外接 Agent。当前支持接入后收到的聊天附件、本地上传和生成文本，不遍历已有群文件目录；Office、PDF 等二进制可以存储和收发，但不解析内容。

## 使用

文件功能默认关闭，在 WebUI「能力 → 文件功能」开启，或设置 `capabilities.files = true`。开关热重载生效，统一控制附件登记、模型工具、插件 SDK 和文件 HTTP 入口；关闭后拒绝新的文件操作，不删除已有原件，原有缓存清理策略继续生效。HTTP 服务器与 WebUI 开关仍各自独立。

- QQ：统一 QQ 适配器的 NapCat、SnowLuma 画像将文件消息与群上传通知作为结构化附件交给 Host。保留适配器原有的通知开关和聊天过滤；接收群上传通知需要开启对应通知设置。
- WebUI：聊天输入框的回形针先上传附件，再随消息发送；「文件」页面按聊天实际名称筛选，提供上传、下载、文本阅读和管理。移除草稿附件不删除原件，可在文件管理中手动删除。
- 模型：`files_list`、`files_download`、`files_read_text`、`files_create_text`、`files_send` 仅接受当前可信执行上下文。文件内容是外部数据，不能作为工具执行指令。
- 管理员：在文件管理页选择目标聊天并确认后才能跨聊天发送。普通工具和 SDK 不提供跨聊天授权接口。

## 存储与配置

`files` 配置节由配置系统生成；不用手动创建目录或改数据库。默认单文件 50 MiB、总量 10 GiB、4 路传输、120 秒超时，文本解析上限 8 MiB（可配置至 50 MiB），文本读取按字符分页，每次最多 32000 字符。

平台附件先登记元数据，明确请求下载或读取时才获取内容；缓存最后访问 30 天后清理。本地上传和生成内容属于原件，保留到手动删除。达到额度会拒绝新增，不自动删除原件。传输按单文件最大容量预留，所以剩余空间不足一个单文件额度时也会拒绝开始传输。并发上限变更后，新操作按新上限准入；已有读取允许结束，调低上限不会重置正在占用的名额。失败或取消释放预留，异常中断每分钟回收，重启时恢复索引并清理孤立临时文件。

数据库 schema 46 新增文件、聊天绑定和解析状态三张表。文件放在实例 `data/files` 中，磁盘名称由 Host 生成，与上传文件名无关；首次写入计算 SHA-256。发送凭证有效期内以及下载响应进行期间，清理、删除会被拒绝，以固定被读取的内容。支持 UTF-8、带 BOM 的 UTF-16，以及显式指定 GB18030，不执行文档脚本或宏。

## 同机与异机部署

文件字节通过公共后端的 `/api/files/transfers/...` 传输。HTTP 服务随主程序启动，`webui.enabled = false` 仅关闭管理页面和管理接口，不影响 QQ 或 SDK 收发文件。`files.transfer_base_url` 留空时使用`http.host` / `http.port` 指定的本机后端地址（默认回环地址、8001 端口）；7999 只是前端开发服务端口。QQ 客户端部署在另一台机器时，填写客户端能访问的主程序地址，并配置后端监听、反向代理与网络访问；跨机器建议使用 HTTPS。

监听配置归属 `[http]`，修改地址或端口后需要重启；`HTTP_HOST` 可追加监听地址。WebUI 开关和防爬虫设置可热重载；重载时旧 WebUI 长连接会关闭并清理订阅，文件通道独立于 WebUI 中间件且不受影响。对外只提供文件传输时，反向代理可以仅转发 `/api/files/`。

平台下载仅允许 HTTP(S)，拒绝 URL 内嵌凭证，实际 DNS 连接及每一跳重定向均检查目的地址，默认禁止内网、回环、保留和组播地址。如果平台提供私网下载地址，管理员须在 `files.trusted_download_origins` 中列出精确的来源，如 `http://192.168.1.20:3000`；不允许通配符或任意用户指定下载地址。

令牌只授权一个操作和一个文件，默认五分钟失效，服务重启全部失效。不要把传输 URL 当作永久文件链接或写进公开日志。可长期引用的是 `file_ref`，后端每次检查聊天授权。

## 插件接入与限制

SDK 2.17.0 的 `ctx.files` 在 Host 派发的工具调用期间可用。声明对应的 `files.*` 精确能力名称；Host 在调用开始签发聊天权限，结束或取消时撤销，SDK 不能靠提交 session_id 选择聊天。定时任务、普通 API 和无聊天上下文的调用会拒绝访问。

SDK 在本地读取上传路径，通过流式 HTTP 上传；下载独占创建本地目标文件并校验大小和哈希。Host 不接受插件在 RPC 中传入的任意本地路径、任意下载 URL 或大段 Base64。主程序兼容已发布的旧 SDK，开发期间可用 `MAIBOT_PLUGIN_SDK_PATH` 指向本地 SDK 仓库；正式使用 `ctx.files` 需要安装含该接口的 SDK 版本。

发送返回 `sent` 或 `unknown`。`unknown` 表示没有取得确定的发送成功回执，平台仍可能稍后投递，必须核对聊天，不自动重发。当前自动验证使用临时实例和模拟适配器；真实 NapCat/SnowLuma 的权限、地址可达性及平台回执仍需在目标部署中验收。
