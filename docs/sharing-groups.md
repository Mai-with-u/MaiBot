# 相通组

相通组独立存于实例数据库。组有稳定 UUID、名称、颜色、默认空备注、启用开关和修改版本；不提供手动排序。修改版本用于检测并发编辑冲突，不是历史版本。

## 数据与扩展

- sharing_groups：组的基本信息与创建/更新时间。
- sharing_group_members：真实聊天流 session_id，组内唯一。
- sharing_group_rules：旧配置中的平台、目标、聊天类型规则。规则持续解析实际聊天流，不生成会话 ID。
- sharing_group_capabilities：组与共享能力的关联，当前注册 expression、jargon、memory。
- sharing_group_migrations：一次性配置导入记录及原配置副本。删除组后保留迁移记录，避免重启时复活。

新增共享能力时，在服务能力注册表中注册，并接入该能力的读取范围。无需修改组表或增加 share_xxx 列。需要额外能力参数时另行增加具有明确结构的版本化数据，不能把业务配置随意塞入未知 JSON 字段。

## 范围

当前聊天的可读范围是自身与直接所属、已启用且开启相应能力的组成员的并集。不会继续沿其他成员所属的组扩展。例如 A/B 与 B/C 两组，A 不能因此读取 C。共享读取不会把来源记录复制或重新归属到当前聊天；用户实际转述产生的新消息仍属于新的聊天事件。

原有学习/使用开关独立生效。关闭组不会删除内容，关闭能力只停止该组对此能力的共享。已有全局公共内容的语义保持不变。

## 迁移

数据库 schema 49 建表。宿主加载配置后在线程池事务性导入各旧组，每个组只启用原来的共享能力，不自动合并同名或相似组。旧全局记忆开关导入为全聊天动态规则组。旧表达空组在运行时没有共享成员，迁移后保持空组。

完成标记和所有组在同一事务提交；失败回滚，重启可重试。配置中的旧字段保留用于首次导入及人工追溯，导入完成后不再参与运行时解析，WebUI 不再提供其编辑控件。配置文件更新不会覆盖数据库组。

运行时使用内存快照，写入后刷新；同步数据库工作由启动线程池和同步 API 端点承担。动态规则会匹配后续创建的运行中聊天流。

## API

GET/POST /api/webui/sharing-groups；PUT/DELETE /api/webui/sharing-groups/{id}。更新必须携带当前 revision，删除通过查询参数提交 revision。并发冲突返回 409。
