# 聊天流迁移

入口：WebUI「数据 → 聊天迁移」。选择已存在的来源和目标聊天流，预览数据，逐条处理配置、表达、黑话及命令冲突，确认覆盖目标长期记忆后执行。不限制平台、账号或群聊/私聊组合。

迁移为复制合并，来源不会删除或改成跳转。目标保持自己的收发身份；历史消息保留原平台、发送者和消息内容。迁移时只暂停双方入站处理、聊天实例和对应记忆任务，其他聊天流继续运行。等待中的入站消息在暂停解除后继续处理；主动暂停状态不因迁移改变。

主数据库范围包括消息、工具记录、用量、观察与回复评估记录、附件绑定、表达、黑话、学习命令、词频、聊天用量汇总和相通组成员关系。附件内容仍使用实例内已有文件。全局资源和插件私有存储不复制。按真实事件统计的实例消息、工具及模型总量不因复制增加。新增带聊天归属字段的数据表若未声明迁移规则，会阻止迁移并显示表名。

配置复制精确匹配来源平台、对象和聊天类型的规则；目标已有规则及覆盖行为在预览中展示。全局配置、适配器账号与收发名单不随聊天迁移改变。目标未设置独立配置或仍使用默认值时，自动采用来源配置并在预览列出；定制配置差异需逐项选择。冲突处理使用按钮，两侧按可读字段展示。所有待处理项都有明确决定后才允许提交。执行前会重新核对数据和配置；预览过期需重新预览。

长期记忆覆盖目标聊天范围的段落归属、事实与证据、情节、图片引用及摘要检查点。保留来源、其他聊天流、全局和人物记忆；按内容哈希共享的向量与图片资产不重复生成。空来源也会清空目标对应范围，执行前必须确认。记忆服务关闭但仍有数据库时会阻止迁移，避免漏迁。

来源账本记录普通记录及聚合贡献，重复迁移只追加新数据或新增贡献，并避免循环迁移重复累加。普通记录按来源聊天流与来源记录 ID 去重，不追踪迁移后的内容修改；已经处理过的记录不重新同步。未迁移记录仍逐项检查表达、黑话和命令冲突。全局黑话不复制；同一条黑话已关联迁移双方时直接跳过，不产生自身冲突或修改共享范围。不同记录即使黑话文字相同，仍保留逐项冲突处理，采用来源时只解除旧目标关联，不影响其他聊天流。

执行在服务端后台继续，离开页面不取消任务。跨数据库、配置和记忆的阶段记录用于失败恢复：主数据库提交前恢复已改动的配置与记忆；提交后完成缓存刷新。恢复遇到后续修改会明确报错，保持双方暂停，不能静默覆盖。进程异常退出后在迁移记录点击「恢复迁移任务」，恢复结束再创建新预览。暂停期间的消息由原入站协程持有，进程退出后的重投递能力取决于适配器。
