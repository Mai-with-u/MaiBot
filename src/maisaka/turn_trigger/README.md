# 群聊查看频率

`chat.reply_timing.talk_value` 及当前规则组给出的值是外部查看频率，表示一批防抖完成的消息进入 Planner 的基础概率，不表示回复概率。配置字段名与插件频率接口保持兼容。私聊保持直接查看，暂停回复设置独立生效。

## 内部状态

- 平常：按外部值抽签，每批只判定一次。未通过的消息保留在缓存中，之后的新消息重新开始防抖。
- 激活：任何来源实际启动 Planner 时，内部频率从外部值开始。衰减期内再次激活不重置。
- 衰减：每次有效 Planner 运行扣减 `1/16`，被新消息打断的请求不扣减。内部频率大于零时，外部判定放行概率始终为 1。
- 耗尽：进入恢复期，仅影响后续外部判定的查看概率。当前 Planner 循环和挂起等待继续由原有机制控制，停止条件及内部循环轮次上限保持不变。恢复期内继续运行 Planner 不重复扣减，也不重置恢复进度。
- 恢复：每次判定按当时内部频率抽签，再增加外部值的 `1/16`，16 次判定恢复到外部值。恢复期内实际启动 Planner 则重新激活。

外部值为 0.3 / 0.5 / 0.7 / 1 时，内部频率分别在 5 / 8 / 12 / 16 次有效 Planner 运行后归零，包含首次运行，这些次数不是 Planner 运行上限。提前停止保留剩余额度。外部值为 0 时普通群聊只维护历史，不进入 Planner；Focus 保持独立调度。

## 静默查看

根据当前上下文窗口与上一轮上下文窗口中外部消息的平均接收间隔，预测下一条消息的到达时间。只有一个窗口能计算间隔时使用该窗口；均不足两条不同接收时刻的消息时不设置预测定时器。媒体处理乱序按实际接收时间排序，麦麦自身发言不参与统计。

超过预测时间没有新消息时，增加一次判定机会，仍经过内部状态对应的概率。未通过则按同一预测间隔等待下一次判定；每个截止点仅判一次。判定必须等当前防抖完成。通过后复用已有上下文进入 Planner，无需伪造用户消息。

同一段静默在成功触发查看后不再重复启动，直到收到新消息。新消息刷新预测，Planner 运行期间暂停静默判定，退出后重新安排；运行时关闭会取消定时任务。
