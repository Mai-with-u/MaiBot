# 群聊查看频率

`chat.reply_timing.talk_value` 及当前规则组给出的值是外部查看频率，表示一批防抖完成的消息进入 Planner 的基础概率，不表示回复概率。配置字段名与插件频率接口保持兼容。私聊保持直接查看，暂停回复设置独立生效。

## 查看与连续思考

普通群消息完成防抖后，每批按当前生效的外部频率抽签一次。未通过的消息留在缓存里，后续新消息重新开始防抖。频率为 0 时普通群聊只维护历史，Focus 独立调度。

Planner 运行期间直接执行后续轮次，新消息由当前循环接入。结束思考或调用 `wait`（含带秒数的等待）时结束这段连续执行。之后的普通消息和静默查看按当前基础概率判定。定时等待到期时，按当时生效的查看概率抽签一次。通过则唤醒 Planner，未通过则结束等待并回到空闲。提前唤醒会取消原倒计时。

## Planner 轮数与还债

普通群聊按回合开始时的有效频率计算常规额度，取 `ceil(16 × 频率)`，频率最高按 1 计算。有效频率低于 0.5 时，同一回合累计最多 8 轮；达到 0.5 时起最多 16 轮。定时等待后继续同一回合时沿用原额度和已用轮数。被新消息打断的请求不计轮。

超过常规额度后可以自动续轮，每完成额外一轮，当前群就欠一轮。例如频率为 0.07，常规额度为 2 轮，连续完成 5 轮后欠 3 轮。所有频率都参与还债，变更频率保留已有欠债。

群友发来一批新消息且本应通过概率判定时，跳过本次查看并抵一轮债。未抽中的批次不抵债。开启强制响应的 @ 或提及可直接唤起，保留已有欠债。欠债期间暂停静默查看和 wait 到期唤醒，群里无人发言时不会自动还债。

## 静默查看

根据当前上下文窗口与上一轮上下文窗口中外部消息的平均接收间隔，预测下一条消息的到达时间。只有一个窗口能计算间隔时使用该窗口；均不足两条不同接收时刻的消息时不设置预测定时器。媒体处理乱序按实际接收时间排序，麦麦自身发言不参与统计。

超过预测时间仍无新消息且防抖已完成时，按当时生效的基础概率抽签一次。通过后复用已有上下文进入 Planner，未通过则继续保持安静。两种结果都会用完这段静默的查看机会。

收到新消息后重新预测下一段静默。Planner 运行期间暂停静默判定，退出后只安排尚未判定的静默。运行时关闭会取消定时任务。
