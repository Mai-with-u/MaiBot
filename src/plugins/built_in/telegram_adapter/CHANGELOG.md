# 更新日志

## 0.1.17 - 2026-10-30

### 细节

- 插件图标：新增简约纸飞机图标，并在插件清单中声明。

## 0.1.16 - 2026-10-29

### 细节

- 插件市场：将 SDK 兼容版本上限修正为 `2.98.99`，解决版本格式校验阻止收录的问题。

## 0.1.15 - 2026-10-28

### 主要功能

- 配置页：新增 Telegram 连接状态及重新连接按钮，填写并保存 Bot Token 后即可启用适配器。

## 0.1.14

### 细节

- 连接：修复底层 SSL 读写异常绕过网络错误处理、导致长轮询任务停止的问题，按既有间隔重连并从持久化游标继续接收。
- 媒体：下载时的 SSL 异常同样按连接故障处理，保留未确认更新重试，避免误记为坏消息后跳过。

## 0.1.13

### 细节

- 输入状态：按 SDK 解包后的聊天流列表读取真实会话，修复选择 reply 后触发输入状态 Hook 时出现 `list indices must be integers or slices, not str` 的错误。
- 消息表态：同步修正聊天流与单条消息查询的返回值处理，保留查询失败原因与跨会话、账号、话题校验。

## 0.1.12

### 主要功能

- 输入状态：选中 reply 并开始生成回复时显示“正在输入”，按聊天和论坛话题刷新，实际发送前停止刷新，Telegram 收到回复后清除提示；断开连接或刷新超过 180 秒时结束任务。
- 消息表态：新增插件工具 `telegram_react_message`，供麦麦自主设置、替换或撤销表态；通过 SDK 查询真实聊天流和目标消息，校验账号、聊天和已记录的话题归属，保留 Telegram 原始失败原因。

### 细节

- 工具作用域：表态工具声明 `platforms="telegram"`，支持作用域的宿主仅在 Telegram 聊天展示和执行。
- 输入状态：每 4 秒刷新一次，状态接口失败记录警告，不影响实际消息收发。

## 0.1.11

### 细节

- 发布信息：统一 manifest、Python 项目元数据和 MIT 版权署名为 MaiBot Team，补齐项目主页、文档和问题反馈链接。

## 0.1.10

### 细节

- 插件标识：将 manifest ID 修正为 `maibot-team.telegram-adapter`，与 SnowLuma、NapCat 适配器的团队命名空间保持一致。

## 0.1.9

### 细节

- 接收：单条消息转换或路由异常不再停止整个任务，原始更新和完整异常持久化到 failed_updates，与游标原子提交后继续接收后续消息。
- 连接：网络、服务端和限流错误仍重连重试，鉴权错误和轮询冲突仍作为连接故障暴露；取消任务和失败记录保存异常不会确认消息。

## 0.1.8

### 细节

- 动图：MP4/WEBM 转 GIF 时不放大小尺寸画面，使用共享调色板减少转换体积，修复普通动图膨胀超过网关帧限制后阻塞接收队列的问题。
- 排查：帧大小超限错误包含原消息 ID 和实际字节数，便于定位具体媒体。

## 0.1.7

### 主要功能

- 论坛话题：接收话题群消息，将各话题作为独立聊天流，文本、媒体、相册和转发回到原话题；General 沿用原群 ID。

### 细节

- 话题：记录创建和改名事件中的名称，显示群名与话题名；未获知名称时显示话题编号。
- 表态与头像：保存消息话题归属，表态通知回到对应聊天流，话题聊天流沿用所属群头像。

## 0.1.6

### 细节

- 回复：修复将上下文 reply_to 锚点误转为 Telegram 引用的问题，只有显式 reply 消息段才发送引用，确保 set_quote=false 不产生引用消息。

## 0.1.5

### 主要功能

- 表态：订阅 Telegram 消息表态事件，将新增、取消、替换及匿名统计作为通知传入 MaiBot，保留原消息引用和事件详情。

### 细节

- 去重：表态通知使用独立 update_id，避免同一消息多次表态被去重丢弃。接收表态要求机器人具有群管理员身份。

## 0.1.4

### 细节

- 头像：补齐用户头像查询，使用 Telegram 当前头像的最大尺寸，通过适配器代理下载并提供给宿主缓存；无可见头像与 API 错误分别处理。

## 0.1.3

### 细节

- 合并转发：移除人工添加的转发标题，将相邻说明文字作为相册下方的 caption，保留 @ 实体与相册回复引用；超过说明上限的文字完整独立发送。

## 0.1.2

### 主要功能

- 合并转发：连续图片使用 Telegram 相册发送，相同发送者的纯图片节点不再重复署名；超过 10 张自动拆组，保留其他内容的顺序与回复引用。

### 细节

- 发送：支持多文件上传并记录相册内全部消息 ID，发送前完整校验媒体，部分发送失败明确返回已发 ID。

## 0.1.1

### 细节

- 头像：提供公开 `adapter.avatar.get` v1 接口，通过 Telegram API 与适配器代理获取群头像，使用本机临时资源交给宿主缓存，避免暴露机器人 Token。

## 0.1.0

### 主要功能

- Telegram：以独立 MessageGateway 插件接入单账号机器人的私聊、普通群和超级群。
- 消息：双向支持文本、图片、静态/动画/视频贴纸、语音、@、回复引用与转发。
- 转发：接收原生转发并保留可见来源，发送原生转发及展开合并转发节点。

### 细节

- 连接：支持 HTTP/SOCKS5 代理、长轮询、配置热更新和网络故障重连。
- 媒体：内置 FFmpeg 依赖完成语音与视频贴纸转换，使用 rlottie 渲染 TGS。
- 路由：使用机器人账号声明身份和聊天范围内唯一消息 ID，白名单统一交给宿主。
- 持久化：按账号保存更新游标与贴纸文件引用，重启后可继续复用原贴纸。
- 错误：发送前校验内容，部分发送失败返回已发 ID，媒体与协议错误明确暴露。
