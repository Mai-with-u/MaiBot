# MaiBot Telegram 适配器

让麦麦通过 Telegram 机器人接收消息和回复，支持私聊、群聊及论坛话题。

适配器随 MaiBot 内置提供，在适配器管理中配置和启停，随主程序更新，无需单独安装。一个适配器实例连接一个机器人。

## 支持的功能

- 私聊、普通群、超级群和论坛话题收发。
- 文字、图片、静态贴纸、动画贴纸和动图收发。
- 接收语音与音频，配合麦麦的语音识别功能理解内容。
- 发送语音，配合 TTS 插件使用。
- @、回复引用、转发及多图发送。
- 生成回复时显示“正在输入”。
- 接收消息表态，让麦麦为消息添加、替换或取消表态。
- 显示可获取的用户头像和群头像。

暂不支持频道接入、消息编辑、按钮交互、普通视频和任意文件。语音识别需要在麦麦中配置 ASR；适配器本身不负责语音合成。

## 开始使用

### 1. 创建机器人

在 Telegram 中打开 [BotFather](https://t.me/BotFather)，发送 `/newbot`，按提示设置机器人名称和用户名，保存获得的 **Bot Token**。

Token 相当于机器人的登录凭据，请勿公开分享。

### 2. 配置并连接

1. 打开 WebUI 的适配器管理，找到「Telegram 适配器」。
2. 在 Telegram 配置中填写 **Bot Token**。
3. 如果需要代理，填写代理地址，例如 `http://127.0.0.1:7890` 或 `socks5://127.0.0.1:7890`；留空表示直连。
4. 启用适配器并保存，在配置页查看连接状态。

Telegram 适配器使用 Token 登录，不需要扫码。修改连接配置并保存后会重新连接，也可以使用配置页的「重新连接」按钮。

### 3. 测试私聊

打开机器人的 Telegram 会话，发送 `/start`，再发送一条普通文字消息。

如果没有回复，检查连接状态、麦麦回复模型，以及 WebUI「适配器策略」中是否允许该机器人接收你的私聊。

### 4. 接入群聊

1. 将机器人加入目标群。
2. 在麦麦的「适配器策略」中放行该群。
3. @机器人发送消息，确认能正常回复。
4. 如果需要接收群内普通消息，在 BotFather 中关闭机器人的 **Privacy Mode**。必要时重新将机器人加入群，或将其设为群管理员。

群和用户的接收范围统一在麦麦「适配器策略」中设置，无需在适配器里另外填写白名单。

## 使用论坛话题

论坛中的不同话题分别显示为独立聊天，名称通常为“群名 / 话题名”，回复会发送到对应话题。

设置接收范围时，请选择对应的话题；放行一个话题不等于放行所有话题。尚未获取到话题名称时，页面可能显示话题编号，General 显示为“群名 / General”。

如果需要手动填写群或话题 ID，请完整复制页面提供的值，保留负号和话题编号。

## 图片、贴纸和语音

- 可以直接向机器人发送图片、贴纸和动图；图片说明会一并接收。
- 相册中的图片会逐张接收。发送多张图片时，适配器会按内容组合或拆分发送。
- 长文字自动分段，混合内容按原顺序发送。
- 接收语音前，先在麦麦中启用并配置语音识别。
- 需要麦麦说话时，另行配置能够生成音频的 TTS 插件。

大文件可能超过接收或处理上限。发送失败时，先尝试压缩内容或拆开发送，再查看日志中的原因。

## 回复引用和转发

麦麦可以识别对机器人的 @ 和回复引用，也支持发送引用回复与转发消息。

原消息被删除、受到内容保护或机器人没有访问权限时，转发可能失败。匿名群管理员和隐藏来源的转发只显示 Telegram 提供的信息，不会猜测真实个人身份。

## 消息表态

麦麦可以根据对话为当前聊天中的消息添加表情，也可以只表态而不发送文字。再次表态会替换此前的表情，也可以撤销。

如果希望麦麦收到群成员添加或取消表态的通知：

1. 将机器人设为群管理员。
2. 重新连接适配器。
3. 在群里为一条消息添加或取消表态，验证是否收到通知。

之前未收到的表态不会补发，匿名表态统计可能延迟。群内允许的表情和操作权限仍受 Telegram 限制。

## 常用设置

| 设置 | 用途 |
| --- | --- |
| Bot Token | BotFather 提供的机器人凭据 |
| 代理地址 | 无法直连时填写 HTTP 或 SOCKS5 代理；留空直连 |
| 网络故障重试间隔 | 默认 5 秒，一般保持默认即可 |
| 媒体下载上限 | 默认每个文件 20 MB，实际还受 Telegram 服务限制 |
| 媒体转换超时 | 默认 60 秒，处理较大媒体时可按需调整 |

其余连接参数一般保持默认。仅在使用自建服务时修改 Bot API 地址。

## 常见问题

**为什么私聊正常，群里没反应？**

检查麦麦的群接收策略，以及机器人在 Telegram 中的 Privacy Mode 和群权限。先通过 @机器人验证收发。

**为什么只有部分论坛话题会回复？**

每个话题有独立聊天和接收规则，请检查是否放行了对应话题。

**电脑已经开了代理，为什么还是连不上？**

适配器需要单独填写代理地址；留空时直接连接，不会自动使用环境中的代理设置。

**提示 Token 无效怎么办？**

检查是否完整复制了 BotFather 提供的 Token。Token 已更换时，在配置页更新并保存。

**为什么提示连接冲突？**

检查是否还有其他程序或重复运行的麦麦使用同一个机器人 Token，关闭重复连接后重试。

**为什么麦麦收到了语音，却无法理解？**

检查麦麦的 ASR 配置、识别服务连接和日志；适配器接收语音不代表语音识别已配置完成。

**为什么没有头像？**

用户或群可能没有设置头像，或当前机器人无法获取该头像。

**发送超时后要立即重发吗？**

先在 Telegram 确认是否已经收到。多段消息可能只发送了一部分，直接重发整条可能造成重复。

**某条消息处理失败后怎么办？**

查看日志中的具体原因，处理网络、媒体大小或格式问题后再尝试发送。单条内容处理失败不会阻止后续消息继续接收。
