# 微信 ClawBot 适配器

通过微信 ClawBot 会话与麦麦私聊，无需运行桌面微信或另外部署 OpenClaw、AstrBot。

适配器随 MaiBot 内置提供，在插件管理页启用或停用，无需单独安装。

## 支持的功能

- 扫码绑定微信账号，最多同时绑定 16 个账号。
- 为账号设置备注名、重新登录或单独移除。
- 私聊文字和图片双向收发。
- 接收微信语音的转写文字。
- 网络异常后自动重连，重启麦麦后恢复已有账号连接。
- 设置允许交互的用户和图片大小上限。

暂不支持普通微信群、好友列表、朋友圈、读取其他会话，以及发送语音。视频、文件和没有转写文字的语音无法读取。表情按普通图片发送，引用回复不会显示微信原生引用框。

## 开始使用

### 1. 启用适配器

在 MaiBot 插件管理中找到「微信 ClawBot 适配器」，打开设置，启用微信连接并保存。连接默认关闭，启用后再添加账号。

### 2. 扫码绑定

1. 打开侧边栏「插件扩展 → 微信账号管理」。
2. 填写便于识别的备注名，点击「添加账号并扫码」。
3. 使用对应微信扫码并确认授权。
4. 等待页面显示「已连接：微信私聊」。

二维码过期后会尝试自动刷新；若仍未完成，请在页面重新发起扫码。

### 3. 测试聊天

在微信机器人会话中先发送一条文字，确认麦麦能够回复，再尝试发送图片或语音。

如果没有回复，检查账号是否已连接、麦麦的回复模型是否已配置，以及「适配器策略」是否允许接收该私聊。

## 管理账号

### 添加多个账号

在「微信账号管理」中重复添加和扫码步骤即可。每个账号独立连接，重新登录或移除其中一个账号不影响其他账号。

同一账号不能重复添加；已有账号需要重新登录时，使用该账号卡片上的「重新扫码」。

### 修改备注名

备注名用于识别账号，也会作为绑定用户后续消息的昵称显示。这是你设置的本地备注，不是微信提供的真实昵称；修改后不会重写历史消息。

### 移除账号

点击对应账号的「移除账号」，清除麦麦保存的该账号登录信息。主程序中的历史聊天记录会保留。

如果还需要在微信端撤销绑定，请到微信 ClawBot 中操作。

## 常用设置

在适配器配置页调整以下选项并保存：

| 设置 | 用途 |
| --- | --- |
| 允许用户（`allowed_users`） | 留空时允许所有收到的用户；填写后只接收指定用户，所有绑定账号共用此列表 |
| 重试间隔（`retry_seconds`） | 连接异常后的重试间隔，默认 5 秒 |
| 图片大小上限（`max_image_mb`） | 默认每张 5 MB，最高可设置为 8 MB |

允许用户列表填写的是聊天会话中显示的**平台用户 ID**，不是通常用于添加好友的微信号。也需要在麦麦的「适配器策略」中允许对应私聊。

## 常见问题

**扫码后仍未连接怎么办？**

确认已经在微信中完成授权，并检查页面提示。二维码过期时重新扫码；网络异常时等待自动重连。

**提示登录失效怎么办？**

在对应账号卡片上点击「重新扫码」，无需先删除账号。

**为什么无法主动发消息？**

先从微信向麦麦发送一条消息，再尝试回复。主动发送受微信服务限制，不能保证在任意时间都可发送。

**为什么收不到语音内容？**

适配器使用微信提供的语音转写文字。没有转写文字时无法读取，请改发文字。

**为什么图片发送失败？**

检查图片是否超过配置的大小上限。可先压缩图片或减少一次发送的图片数量，再按页面或日志提示重试。

**提示发送超时，要立即重发吗？**

先在微信确认是否已经收到，避免重复发送。

**为什么只能与机器人私聊，看不到其他聊天？**

本适配器只接入微信 ClawBot 会话，不读取普通微信聊天、群聊、好友列表或朋友圈。
