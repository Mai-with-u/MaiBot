# MaiBot QQ 官方机器人适配器

让麦麦通过 QQ 官方机器人接收群聊和私聊消息，并在 QQ 中回复。

适配器随 MaiBot 内置提供，在插件管理页启用或停用，随主程序一起更新，无需单独安装。

## 支持的功能

- 群聊与私聊消息接收、回复。
- 发送文字、@、图片、表情、语音、视频和文件。
- 扫码登录，以及手动填写机器人凭据。
- 搜索用户、复制用户 ID、查看登录状态。
- 群号与 QQ 号绑定，查看、搜索和批量删除绑定。
- 与 SnowLuma / NapCat 协作，静默补充群成员资料。
- 禁言、解除禁言、撤回消息和移除群成员。

暂不支持戳一戳。语音合成需要另行配置 TTS 插件。

## 开始使用

### 1. 准备机器人

在 [QQ 开放平台](https://q.qq.com/)完成开发者入驻并创建机器人，按控制台提示配置测试用户、测试群及所需能力。

在 MaiBot 插件管理页启用「QQ 官方机器人适配器」。

### 2. 登录机器人

可以选择扫码登录或手动配置。

**扫码登录：**

1. 打开 WebUI 的「QQ 官方适配器」页面，进入「登录状态」。
2. 打开「登录设置」，发起扫码登录。
3. 使用手机 QQ 扫码，确认授权的是需要接入的机器人。
4. 授权完成后自动保存并连接，在页面确认状态为「已连接」。

也可以在适配器配置页使用扫码登录控件。二维码过期后可重新生成，等待期间可以取消。

重新授权会替换当前机器人凭据。

**手动配置：**

1. 在 QQ 开放平台控制台取得机器人的 **AppID** 和 **AppSecret（ClientSecret）**。
2. 打开适配器配置中的「QQ 开放平台」，填写并保存。
3. 到「登录状态」确认机器人已连接。

### 3. 测试收发

在测试群中 **@机器人发送一条文字消息**，或使用测试用户给机器人发私聊。

如果没有回复，依次检查：

- 适配器是否已启用，登录状态是否为「已连接」。
- 当前用户或群是否在 QQ 开放平台允许的测试范围内。
- WebUI 的「适配器策略」是否允许接收该群或私聊。
- MaiBot 的回复模型是否已经配置。

## 查看用户和复制 ID

在「QQ 官方适配器 → 用户列表」中，按昵称或 ID 搜索用户，点击复制按钮获取用户 ID。

默认使用 **OpenID**：这是 QQ 官方机器人识别用户的 ID，不是普通 QQ 号。设置权限或保护名单时，请使用当前模式下的用户 ID。

## 使用 QQ 号映射

「启用映射」默认关闭。可在适配器配置的「其他来源信息同步」中修改，也可通过 QQ 官方适配器页面右上角的模式切换按钮修改。

| 模式 | 用户 ID |
| --- | --- |
| 原始 OpenID 模式 | 使用官方 OpenID |
| QQ 号映射模式 | 已绑定的用户使用 QQ 号，未绑定的用户仍使用 OpenID |

切换模式不会搬迁历史数据；同一个人可能因此显示为不同的用户或私聊。关闭映射也不会删除已有绑定。

### 绑定群号和 QQ 号

先在本体「命令管理」中为操作人员授予对应绑定命令的权限，再向机器人发送：

| 命令 | 用途 |
| --- | --- |
| `/assign_group_id 123456789` | 将当前群绑定到指定群号，仅群聊可用 |
| `/assign_id 123456789` | 为自己绑定 QQ 号 |
| `/assign_id @某人 123456789` | 为被 @ 的用户绑定 QQ 号 |

用户绑定仅在启用映射后用于切换用户 ID。群号绑定独立于用户映射开关；修改群号绑定可能产生新的聊天会话。

### 查看和删除绑定

映射模式下，页面会显示「群映射」和「用户映射」。可以搜索、分页浏览、删除单条绑定，也可以多选或全选筛选结果后批量删除。

删除绑定不会删除人物资料和历史消息。开启静默同步时，后续群消息仍可能重新建立自动关联。

## 群成员静默同步

同时使用 QQ 官方适配器和 SnowLuma / NapCat 时，可自动关联群成员身份，并补充官方消息未提供的昵称、群名片。整个过程不需要成员发送验证码，也不会向群内发送验证消息。

设置步骤：

1. 更新官方适配器及 SnowLuma / NapCat 连接器，确保两边都能收到目标群的消息。
2. 在目标群使用 `/assign_group_id 群号` 完成群号绑定。
3. 在「其他来源信息同步 → 关联QQ号」填写 SnowLuma / NapCat 登录的机器人 QQ 号。
4. 打开「静默同步群成员身份」，保存配置。
5. 等待成员正常聊天后，在「用户映射」中查看关联结果。

同步需要两边收到足够的有效文字消息，不会立即完成；只有图片、很短的文字或重复消息时，可能无法完成匹配。有身份冲突时不会强行关联。

静默同步与「启用映射」是两个独立开关：可以补充群成员资料，同时继续使用 OpenID。它不负责通过群聊资料补全私聊昵称。

### SL 仅作身份查询

如果希望由官方适配器负责收发，SnowLuma / NapCat 只协助识别身份，可以打开「SL 仅作身份查询」。该选项默认关闭，需要先正确填写「关联QQ号」。

官方连接正常时，SnowLuma / NapCat 暂停向麦麦投递该账号的消息，避免重复接收和回复；官方连接失效后会自动恢复普通收发。暂停期间的消息不会在恢复后补发。

## 群管理工具

在适配器配置页分别设置「禁言工具」「撤回工具」「踢人工具」，保存后生效。启用后，麦麦可以在对话中调用对应工具。

| 工具 | 默认状态 | 可配置内容 |
| --- | --- | --- |
| 禁言、解除禁言 | 开启 | 允许群、保护用户、最短及最长禁言时长 |
| 撤回消息 | 开启 | 允许群 |
| 移除群成员 | 关闭 | 允许群、保护用户 |

- **允许群**留空表示不限制群；可通过选择器搜索并添加指定群。
- **保护用户**中的成员不会被对应工具禁言或移除。禁言与踢人的保护名单分别设置。
- 关闭映射时，保护名单按 OpenID 匹配；开启映射时，也可匹配关联 QQ 号。
- 工具能否执行取决于机器人实际拥有的群管理权限和 QQ 平台开放能力。仅打开工具开关不会取得权限。

### 使用示例

可以结合目标成员的消息，让麦麦“把这个人禁言两分钟”“解除他的禁言”或“撤回刚才那条消息”。实际是否调用工具由麦麦的对话判断决定。

禁言时长填 `0` 表示解除禁言。保护名单不阻止解除禁言。

撤回受消息发送时间及管理权限限制；私聊只能撤回机器人自己的消息。移除群成员需要平台为机器人开放相应能力。

## 常见问题

**为什么用户显示的是一串 OpenID？**

官方消息可能没有提供昵称。可以在用户列表中搜索和复制 ID；群成员资料可通过静默同步补充。

**为什么绑定了 QQ 号，用户 ID 仍然是 OpenID？**

绑定只保存关联关系，还需要打开「启用映射」。

**为什么绑定后仍无法操作某个成员？**

检查绑定是否正确、机器人是否收到过该成员的消息，以及机器人是否拥有对应管理权限。

**为什么一条回复被拆成了多条？**

包含文字和多种附件的回复可能分开发送，属于正常现象。

**为什么发送或管理操作失败？**

先查看日志中的失败原因，检查文件格式和大小、机器人权限及平台发送限制，再按提示调整。
