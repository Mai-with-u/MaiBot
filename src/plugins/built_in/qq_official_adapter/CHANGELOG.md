# Changelog

## 未发布

### 主要功能

- 语音发送：群聊和单聊支持 SILK、MP3、WAV、OGG 语音，复用分片上传与被动回复序号；明确拒绝非法数据、未知格式及超过 20 MB 的语音。
- 身份查询模式：新增默认关闭的「SL 仅作身份查询」开关，官方连接在线时持续续期，暂停关联 SL/NapCat 账号的消息和通知入站投递，保留身份采集；15 秒未续期自动恢复，正常停用主动释放，SL 不持久化暂停状态。
- 映射页面：合并展示手动与自动用户映射，显示 QQ 号、昵称、群名片、所属群、绑定来源和冲突状态，自动记录支持按群加载对应 QQ 头像。
- 群成员身份：群绑定后与 SnowLuma / NapCat 通过公开 API 静默匹配消息指纹和时间，三条不同正文一致后同步 QQ 号、昵称与群名片；人工映射优先，候选、消息缓存及确认结果均有限额和过期规则，冲突暂停自动绑定。

### 修复

- 身份查询模式：短暂断线保留剩余租约，重连时先确认 SL 已暂停再开放官方路由，修复重连期间两侧同时发送的问题。
- 回复引用：仅在主程序提供标准 `reply` 段时生成引用框，不再把用于被动发送的 `reply_to` 上下文强制转换为引用，修复引用过于频繁、连续分段都显示引用的问题。
- 身份查询模式：同步撤销 SL/NapCat 的出站路由，修复仅暂停入站后同一回复仍被两个网关广播发送的问题；租约到期独立恢复收发路由，保留身份查询连接。
- 映射页面：头像、刷新和登录操作共享桥接请求队列，头像逐个加载，修复并发超限导致头像显示 “Two requests are already running”。
- 入站引用：在同一账号和会话的内存缓存中反查 QQ 引用索引，生成标准 `reply` 段，支持引用用户和机器人消息；缓存最多 2000 条、保留 24 小时，重启或淘汰后无法解析旧引用，正文仍正常接收。

## 0.4.6 - 2026-10-27

### 修复

- 回复引用：出站消息携带官方 `message_reference`（REFIDX），QQ 客户端正确渲染回复引用样式。此前仅发送 `msg_id/msg_seq`（被动回复额度凭证，本身不产生引用），导致后台显示回复引用但 QQ 客户端没有引用样式。
- 入站解析 `message_scene.ext` 的 `msg_idx` 并建立“平台消息 ID → REFIDX”映射，自发消息同时保存响应 `ext_info.ref_idx`；`codec` 出站不再丢弃 reply 段。查不到引用索引时按无引用降级发送，不阻断消息。
- 引用兼容：`msg_type=2` 的 markdown 消息（含 @ 段）不再注入 `message_reference`。实测 Mac QQ / 部分手机 QQ 对 markdown+引用会重复渲染正文（卡片 + 纯文本），文本/图片消息的引用样式不受影响。

## 0.4.5 - 2026-10-29

### 细节

- 插件市场：将 SDK 兼容版本上限修正为 `2.98.99`，解决版本格式校验阻止收录的问题。

## 0.4.4 - 2026-10-28

### 主要功能

- 登录：新增 QQ 扫码授权，支持生成、刷新、取消和过期重试，授权成功后保存凭据并自动连接。
- 配置页：新增二维码、连接状态和重新连接操作，二维码及临时状态不写入配置文件。
- WebUI：新增群与用户映射页面，展示 OpenID 对应的群号、QQ 号、头像、类型和绑定数量，支持刷新及头像按需加载。

### 细节

- 连接：按网关关闭码刷新失效 Token、重置失效 Session；限流时延迟重连，不可恢复错误停止重试。
- 消息：普通断线保留已接收的入站任务，恢复就绪后继续投递，避免漏消息。
- 配置：新增高级设置，将断线重连间隔移入该栏。


## 0.4.3 - 2026-10-23

### 修复

- 消息归属：通过正式 account_id/scope 字段传递机器人身份，保留统一账号映射，不再在 additional_config 或 route_metadata 中写入身份字段。

## 0.4.2 - 2026-10-22

### 修复

- 工具作用域：禁言、撤回工具仅在 QQ 平台展示和执行，修复向 Telegram 等其他平台暴露的问题。

## 0.4.1 - 2026-10-04

### 新增

- 界面：新增低饱和灰蓝配色的抽象企鹅适配器图标，用于插件列表、详情和配置页面。
- 头像：新增 `adapter.avatar.get` 用户和群头像查询接口，与 SnowLuma 协议一致，支持数字 ID 及已绑定数字 ID 的 OpenID，返回资源 URL 与有效期供宿主统一缓存。

### 修复

- 禁言、撤回工具默认启用，未填写 `allowed_groups` 或留空时允许所有群使用；保留显式关闭开关与非空群白名单限制。

### 变更
