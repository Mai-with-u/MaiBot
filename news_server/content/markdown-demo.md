资讯正文支持常用的 Markdown 语法，卡片会把它完整渲染出来。

## 支持的写法

- **加粗**、*斜体*、~~删除线~~
- `行内代码` 与代码块
- [链接](https://github.com/Mai-with-u/MaiBot)
- 有序与无序列表

```python
print("麦麦你好")
```

> 引用块也可以正常显示。

| 字段 | 说明 |
| --- | --- |
| title | 标题 |
| summary | 摘要 |
| date | 发布时间 |
