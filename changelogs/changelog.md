# 更新日志

# [1.3.0] - 2026-9-15

## Maisaka

- 图片嵌入自动兼容百炼与豆包官方地址：`client_type=openai` 时按 Provider 地址切换各自原生多模态嵌入协议，无需再配置 image_embedding_input/image_embedding_body 模板；显式模板仍优先生效，并补充精确的图片向量协议指纹。
- 新增内置三维建模工具，支持基础几何体组合、OBJ/STL/PLY/GLB 静态网格导入、部件编辑和 GLB/STL 导出；模型按聊天流隔离并保留编辑前版本。
- 新增三维模型 CPU 预览渲染，PNG 图片返回 Planner 上下文，支持看图后继续修改及通过现有发图能力展示预览。
- 内置三维建模工具改为由实验性开关 `experimental.enable_3d_modeling`（默认关闭）统一启停，关闭时不会出现在工具列表和 `tool_search` 结果中。
- 修复 reply 工具返回未知回复风格时整轮回复失败的问题，未知值按默认「正常回复」处理并记录警告。
- 长期记忆持久化空摘要触发进度，修复重启后重复总结和图片证据校验失败仍写入段落的问题。
- 图片记忆修复描述补偿标识冲突、检索故障被当作无匹配、热开启后无法入队及单张失败阻断后续图片的问题。
- 图片记忆管理调用统一回到主循环，卸载期间保持发布锁，并在退出时等待图片描述同步。

**注意：此版本改动内容较多，请阅读以下说明**

- Q：为什么更新后麦麦说话太多/太少？
- A：1.0.8更新了maisaka的发言机制，可能对于不同的人设会有不同的变化，你可以 1.修改人设或提示词；2.调整回复频率模式 3.调整回复频率数值 来尝试微调

- Q：为什么麦麦出现了连续回复或者回复自身？
- A：可以尝试 1.修改planner的提示词 2.开启 聊天-标记自身消息 3.避免使用参数量过小的planner模型 4.修改 聊天 - 什么时候发言 - "连续 wait 上限" ，调低该数值可以降低性能较弱模型的连续回复情况。
